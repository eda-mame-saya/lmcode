# 詳細設計：概要と読み方

最終更新: 2026-10-27

本フォルダ（`document/詳細設計/`）を **詳細設計の正本** とする。  
上位方針は `document/基本設計/`。矛盾する場合は **基本設計の方針を優先**し、本フォルダは画面・IF・実装形で具体化する。

本リポジトリは **コーディングアシスト専用アプリ（LMCode）**。残存画面は **S11／S11a／S16**。

---

## 1. ターゲット（当面）

| 項目 | 内容 |
|------|------|
| リリース像 | 社内検証・コーディング Agent の実用 |
| OS | **macOS**／**Windows**（Swift 補完は macOS のみ） |
| 保存 | **完全ローカル** |
| 生成AI | **llama.cpp**（`llama-server`） |
| 言語サーバ | Dart Analysis Server／SourceKit-LSP（任意・WS 種別に応じ） |
| スマホ | 対象外 |

---

## 2. 詳細設計で決めること／決めないこと

| 決める | 当面決めない（甘くてよい） |
|--------|---------------------------|
| 画面一覧・遷移・各画面の要素と操作 | ピクセルパーフェクトな見た目 |
| 主要状態（空／準備中／エラー） | 非機能の数値目標 |
| ローカルファイル／JSON の実装形 | 認証本運用 |
| LLM／LS のアプリ側契約（起動・失敗時） | 全言語 IDE 互換 |

---

## 3. 文書構成

```text
document/詳細設計/
├── 00_概要と読み方.md          … 本ファイル
├── 画面/
│   ├── 00_画面一覧と遷移.md
│   ├── S11_エンジン設定.md
│   ├── S16_*.md
│   └── UI共通_モーダル基本系.md
├── IF/                         … llama-server / Dart LS / SourceKit
└── データ/                     … coding_assist・端末設定・フォルダ規約
```

| 優先順 | 成果物 | 状態 |
|--------|--------|------|
| 1 | 本ファイル・画面一覧と遷移 | **済** |
| 2 | S11／S16 | **済**（実装追随） |
| 3 | データ詳細 | **済**（coding_assist 中心） |
| 4 | IF | **済**（LLM／Dart／SourceKit） |

鳥瞰用の画面マップは `document/画面構成/00_全体イメージ.md`。

---

## 4. 画面ID採番ルール

* 形式: **`S` + 二桁番号**。本アプリで実装するのは **S11／S11a／S16** のみ。
* ダイアログは親画面の節に書く。必要なら枝番。

---

## 5. 各画面ドキュメントのテンプレ

各 `Sxx_*.md` は次を最低限書く（ワイヤー級で可）。

1. 目的／前提状態  
2. 表示要素  
3. 操作と遷移  
4. 空状態・エラー・準備中  
5. OS 差分  
6. 対応する基本設計シーケンス（参照リンク）
