| 項目 | 内容 |
|------|------|
| 画面ID | **S17** |
| フェーズ | 設定 |
| 目的 | Agent が使う system／＋メニュー／内部フロー用プロンプトをユーザーが個別上書きする |
| 上位 | [S16_コーディングアシスト.md](./S16_コーディングアシスト.md)、[DATA_端末設定.md](../データ/DATA_端末設定.md) |

---

## 1. 入口

S16 ツールバーの **エンジン設定（tune）の右隣**に `edit_note` アイコン。「カスタムプロンプト」。生成中／LLM ビジー時は無効。

---

## 2. レイアウト

```text
┌────────────────────────────────────────────────────────────┐
│ ← カスタムプロンプト                                        │
├────────────────────────────────────────────────────────────┤
│ ■ 注意バナー（Agent／アプリ連携が壊れる可能性）              │
│ ■ System／共有ルール 一覧（変更済チップ）                    │
│ ■ ＋メニュー／送信時指示 一覧                               │
│ ■ 内部フロー 一覧                                           │
└────────────────────────────────────────────────────────────┘

編集時:
│ 注意バナー / [デフォルトに戻す] [このプロンプトを保存]       │
│ パス例 WS 種別（プレビュー用）                              │
│ プロンプト本文（複数行）                                    │
│ ■ 適用テスト: サンプル入力 → 合成プレビュー → [LLM で試す]  │
```

---

## 3. 挙動

| 項目 | 方針 |
|------|------|
| 保存 | **プロンプト単位**。組み込みと同一内容なら上書きを消す（＝デフォルト） |
| リセット | 当該 ID のみクリア。一括リセット UI は置かない |
| 反映 | 保存直後から次の Agent 送信に効く（llama-server 再起動不要） |
| 警告 | 一覧・編集の両方で、Patch／tool／印の変更が連携を壊しうる旨を明示 |
| テスト | 合成プレビュー必須。任意で localhost LLM へワンショット（会話に残さない） |

プレースホルダ: 検証報告・ループ続行は `{{verdict}}`／`{{blocks}}`／`{{lastBody}}`／`{{currentBody}}` を実行時置換。
