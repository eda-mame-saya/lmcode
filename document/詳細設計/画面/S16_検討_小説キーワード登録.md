# S16：小説キーワード登録

最終更新: 2026-11-06  
状態: **実装済（初版）**

## 目的

登場人物・地名などを Markdown で管理し、執筆中に折りたたみペインで参照する。

## 構成

| # | 方針 |
|---|------|
| 1 | 小説 WS オープン時にルートの `keywords.md` を自動作成（無ければテンプレ） |
| 2 | 編集は `keywords.md` をエディタで直接編集（専用フォームは持たない） |
| 3 | エディタと Agent のあいだにキーワード専用ペイン（Agent と同様に折りたたみ・幅可変） |
| 4 | リストは `#`／`##`／`###`／`####`… 見出しで展開。本文は Markdown 表示（太字・取消線など） |

### 見出し例

```markdown
# 登場人物
## 主人公（名前：タロウ）
物語の主人公
### 所持スキル
魔法
剣術
瞬間移動
```

## 実装

| 項目 | 内容 |
|------|------|
| パス | `keywords.md`（WS ルート） |
| 表示条件 | `CodingWorkspaceKind.novel` のときだけ |
| 同期 | タブで開いていればタブ本文、否则はディスク確保済み本文。再読込ボタンあり |
| 解析 | `CodingNovelKeywordParser` |
| UI | `_NovelKeywordsPane`（`coding_novel_keywords_pane.dart`） |
