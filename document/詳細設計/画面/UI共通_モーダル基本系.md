最終更新: 2026-10-05

| 項目 | 内容 |
|------|------|
| 種別 | **共通コンポーネント**（独立画面IDなし） |
| 目的 | 確認・警告などモーダルの見た目と基本操作の共通仕様 |
| UI原案 | `document/画面構成/モーダル基本系.pdf`（`~/Downloads/モーダル基本系.pdf` を格納） |
| 適用例 | S13 履歴削除確認、会議中サイドバー離脱確認、モデル変更確認 等 |

個別モーダルの文言・ボタンラベルは各画面仕様に従う。**見た目・構造は本資料を正**とする。

## 2. 構成要素

| 要素 | 仕様 |
|------|------|
| 背景オーバーレイ | 半透明の黒（透過黒）。背面は操作不可 |
| カード | 中央配置。白地。軽いドロップシャドウ可 |
| タイトルバー | **プライマリ色**（濃いオレンジ `#E65100`）帯。白文字。左寄せ「タイトル」相当 |
| 本文 | 白背景。確認文言（複数行可）。十分な余白 |
| キャンセル | 左。**グレー塗り**＋白文字（または同等の弱アクション） |
| OK／確定 | 右。**プライマリ塗り**＋白文字（原案の「OK」。画面により「削除」「変更」等に差し替え可） |

ボタンは角丸矩形。横並び・右寄せまたは中央寄せは実装で揃える（原案は左右2つ）。

## 3. 操作（共通）

| 操作 | 既定挙動 |
|------|----------|
| キャンセル | モーダルを閉じる。処理しない |
| OK／確定 | 呼び出し側の確定処理を実行し、閉じる |
| オーバーレイクリック | **閉じない**（誤操作防止。確認系の既定） |
| Esc | キャンセル相当で閉じてよい（任意） |

危険操作（削除等）では OK 側ラベルを「削除」にし、必要なら強調色を検討（初期はプライマリのままで可）。

## 4. カラー（ブランドとの関係）

| 役割 | 値（目安） |
|------|------------|
| タイトルバー／OK | `#E65100`（ブランド プライマリ） |
| キャンセル | グレー系 |
| 本文地 | 白 |
| オーバーレイ | 黒＋アルファ（例: 40〜60%。実装調整可） |

`lib/theme.dart` のトークン経由で参照する。

---

## 5. 利用画面との関係

| 画面 | 用途（例） |
|------|------------|
| S13 | 履歴ゴミ箱 → 削除確認（タイトル例:「会話の削除」、OK→「削除」） |
| S05／S06 | サイドバー離脱確認、終了確認 |
| S11／S13 | モデル変更確認 |
| その他 | 同様の確認が必要なとき本基本系に合わせる |

文言・ボタン数（OKのみ等）は画面側で変えてよいが、**透過黒背景＋プライマリタイトル帯＋本文＋フッターボタン**の骨格は維持する。
