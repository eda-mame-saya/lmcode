# 基本設計：セキュリティ・プライバシー

最終更新: 2026-10-27  
社内向け。細部は甘くてよいが、**機微データの扱い方針**はここに固定する。

---

## 1. 扱うデータの機微度

| データ | 機微度 | 置き場 |
|--------|--------|--------|
| ワークスペースのソース | 高（社内コード） | ユーザーが開いたフォルダ（アプリ外） |
| Agent 会話・tool 要約 | 中〜高（コード断片を含みうる） | `LMCode/coding_assist/threads/` |
| 開いているファイル取り込み | 中〜高 | 送信前はメモリ。送信後は会話 content |
| エラー表示（AI デバッグ） | 中（プロンプト断片を含みうる） | 端末表示。任意共有 |
| GGUF モデル | 低（成果物ではない） | `LMCode/local_llm/models/` |

---

## 2. データの流れ原則

1. **ソースと会話は端末外に出さない**（本スコープ）。Drive 連携なし。  
2. 生成AIは **localhost の llama-server** のみ（クラウド LLM を正としない）。  
3. 言語サーバもローカルプロセス（stdio）。  
4. 保守用テレメトリ（将来）に **ソース本文・会話全文を載せない**。

---

## 3. 認証・秘密情報

| 項目 | 方針 |
|------|------|
| ログイン | 初期不要 |
| llama-server | ローカルホストのみ。外部公開しない |
| ログ | APIキー・秘密をエラー文言や共有ログに出さない |
| クラウドキー | 本アプリでは扱わない |

---

## 4. 保存・削除（方針レベル）

| 項目 | 方針 |
|------|------|
| 保存期間 | アプリによる自動削除は初期しない。部門ルールに委ねる |
| 削除 | ユーザーがローカルフォルダ／会話を削除する。遠隔一括消去は行わない |
| 持ち出し | メール／Slack 等への手動送付は利用者責任 |

---

## 5. プロンプト・AI 利用

| 項目 | 方針 |
|------|------|
| 入力 | ユーザー指示＋開いているファイル／選択範囲／tool 結果 |
| Agent 書込 | 自動実行 OFF では人手承認。ON では Update／Add を自動（S16） |
| ワークスペース外 | tool のルートは開いた WS に限定する方針（詳細は S16） |

---

## 6. プロセス・通信面

| 項目 | 方針 |
|------|------|
| サイドカー待受 | `127.0.0.1` のみを原則とする |
| ファイアウォール | 外部からの LLM ポート公開を想定しない |
| 子プロセス | アプリ終了時に自動起動分を停止 |
| 配布物改ざん | 署名付きインストーラ。社内ポリシーに従う |

---

## 7. 権限（OS）

| 権限 | 用途 |
|------|------|
| ファイルアクセス | ベースフォルダ・開いたワークスペース |
| （マイク等） | **不要**（本アプリ） |

拒否時は当該機能を開始せず、理由を表示する。
