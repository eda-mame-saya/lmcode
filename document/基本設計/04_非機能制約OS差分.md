## 2. 固定する制約（現時点）

| 制約 | 内容 |
|------|------|
| ネットワーク非依存（本体） | ローカル LLM・ローカル保存はネット不要 |
| 生成AI任意 | OFF 時もエディタ・ターミナルは利用可 |
| ログイン不要（初期） | 認証サーバー障害で作業を止めない |
| Drive なし | 成果物はユーザー WS と手元ファイル |
| GGUF ユーザー責任 | 同梱せず、取り込み・ライセンスは利用者 |

## 4. 実行環境の前提

| 項目 | 前提 |
|------|------|
| RAM | **32GB 以上**（コーディング・14B 級） |
| GPU | 必須としない（ビルドオプションは実装次第） |
| Dart／Flutter SDK | 補完利用時。S11 でパス指定または PATH |
| Xcode | Swift 補完利用時（macOS） |

---

## 5. 信頼性・保全（方針レベル）

* 会話は送信完了単位で `coding_assist/threads` に保存。
* 未保存エディタバッファは戻る／終了時に確認（S16）。
* 自動起動したサイドカーは親終了に追随。
