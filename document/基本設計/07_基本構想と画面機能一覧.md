# 基本構想と画面機能一覧

最終更新: 2026-10-27

本ドキュメントは、**LMCode（コーディングアシスト）** の基本構想と現行画面機能の鳥瞰である。  
詳細な画面仕様は `document/詳細設計/画面/`（Sxx）、スコープの正本は [00_概要とスコープ.md](./00_概要とスコープ.md)。

---

## 1. 基本構想

| 項目 | 内容 |
|------|------|
| プロダクト | **LMCode** — 社内向けデスクトップ・コーディングアシスト |
| 狙い | ローカル LLM によるプログラム編集・Agent・エディタ支援を端末内で完結させる |
| 対象 OS | **macOS**／**Windows**（Swift 補完は macOS のみ） |
| データ | **ローカルのみ**。会話は `LMCode/coding_assist/`。ソース正本はユーザー WS |
| 生成 AI | **llama.cpp（`llama-server` + GGUF）**。コーディング用モデルを個別選択 |
| 認証 | ログイン不要 |
| 配布方針 | ワンパッケージ目標（GGUF はユーザー追加） |

### 1.1 ユーザーが辿る流れ（要約）

```text
起動（S16）
  → プロジェクトフォルダを開く
  → 編集／Agent／ターミナル
  →（任意）S11／S11a でモデル・SDK 設定
```

---

## 2. 画面と機能一覧

| ID | 画面 | 主な機能 |
|----|------|----------|
| **S16** | コーディングアシスト | **起動画面**。左メニュー／エディタ／Agent／ターミナル／多言語 WS／補完・定義／自動実行・Flutter 自動検証 等 |
| **S11** | エンジン設定 | llama.cpp（ON／接続／コーディング用モデル・ctx・thinking）、Dart SDK パス |
| **S11a** | モデル追加 | ローカル GGUF 取り込み・表示名登録（ライセンスはユーザー責任） |

確認モーダルの見た目は [UI共通_モーダル基本系.md](../詳細設計/画面/UI共通_モーダル基本系.md)。
