# 基本設計：データ設計

最終更新: 2026-10-27  
保存先は **完全ローカル**。Google ドライブは対象外。  
JSON の厳密な形は詳細設計（`詳細設計/データ/`）を正とし、本章は意図とファイル一覧を固定する。

アプリデータルートは **`LMCode/`**。

---

## 1. ルートとベースフォルダ

| 項目 | 方針 |
|------|------|
| ルート名 | `LMCode/` |
| デスクトップ | ユーザーが **ベースフォルダ**を指定（未設定時は既定パス可）。その直下に `LMCode/` |
| システム用 | `local_llm/`・`coding_assist/` はユーザープロジェクトではない |
| ソース正本 | S16 で開いた **ワークスペース**（任意パス）。`coding_assist/` 配下ではない |

```text
{ベース}/LMCode/
├── local_llm/
│   └── models/          … GGUF（ユーザー取り込みのみ。同梱なし）
└── coding_assist/       … 直近ワークスペース・フォルダ展開（会話は保存しない）
    └── index.json
```

---

## 2. coding_assist（要約）

| 置き場 | 役割 |
|--------|------|
| `index.json` | 直近ワークスペースとフォルダ展開。会話は置かない |

詳細は [DATA_コーディングアシスト.md](../詳細設計/データ/DATA_コーディングアシスト.md)。

---

## 3. 端末内設定（非ファイルツリー）

SharedPreferences 等。

| 項目 | 例 |
|------|----|
| ベースフォルダパス | 絶対パス |
| 生成AI使用 ON/OFF | bool |
| コーディング用モデル／ctx／thinking | ユーザー取り込み GGUF。ctx 既定 **131072（128k）**、上限 **256k** |
| カスタムモデル登録一覧 | 表示名・ファイル名 |
| Agent自動実行 | bool（S16 ツールバー） |
| Dart／Flutter SDK パス | 空＝PATH 探索 |
| S16 UI フォント等 | メニュー／エディタ／Agent |

詳細キーは [DATA_端末設定.md](../詳細設計/データ/DATA_端末設定.md)。  
会議用／チャット用キーが残っていても **本アプリではコーディング用のみ使用**（互換残置可）。

---

## 4. 除外・非目標

* Google ドライブ上のフォルダ ID 管理
* クラウド同期用メタデータ
* 会議・ASR・カレンダー・S13 用ツリー（`ai_chat/` 等）の新規利用
* ソースを `coding_assist/` へ丸ごと複製すること
