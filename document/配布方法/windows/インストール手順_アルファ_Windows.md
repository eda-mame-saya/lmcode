# LMCode インストール手順書（アルファ版・Windows）

最終更新: 2026-10-29  
対象: **Windows 10 / 11（64bit）**  
関連: `document/基本設計/05_運用配布保守.md`、`document/基本設計/08_Windows対応_実装方針.md`、同梱 `README_はじめにお読みください_Windows配布.txt`

まず同梱の **`README_はじめにお読みください_Windows配布.txt`** を読む。

---

## 0. 全体像

| 区分 | 内容 | 必須度 |
|------|------|--------|
| **A. アプリ本体** | `lmcode.exe` ＋ `data\` ＋ DLL | 必須 |
| **B. ローカル LLM** | `local_llm\`（`llama-server.exe`）。**GGUF はユーザー追加** | Agent 利用時 |
| **C. 初回** | 保存先に `LMCode\` 作成 | 自動／手動 |

```text
[展開] LMCode-Windows.zip（名称は配布に従う）
         ├─ lmcode.exe / data / *.dll
         └─ local_llm/    （llama-server。models は空でも可）
              │
              ▼
[起動] lmcode.exe → S16（コーディング画面）
              │
              ▼
[利用] フォルダを開く／編集／Agent。モデルは S11a で追加。
```

## 1. 動作環境

| 項目 | 目安 |
|------|------|
| OS | **Windows 10 / 11（64bit）** |
| メモリ | コーディング用途は **32GB 推奨**（14B 級）。検証のみなら 16GB でも可（遅い） |
| ディスク | 展開＋ユーザー GGUF 分 |
| GPU | 必須としない（CPU 可） |
| ネット | pull 不要（ローカル完結） |

|--------------------|------|

| `local_llm\` | `llama-server.exe` 等。`models\` に GGUF を追加 |

---

## 3. 初回〜モデル追加

1. zip を展開し、フォルダごと任意の場所へ置く  
2. `lmcode.exe` を起動（S16）  
3. S11a（モデルを追加）で `.gguf` を取り込む  
4. コーディング用モデル／ctx（既定 128k）を選択して保存  

Ollama が動いている場合は停止する（ポート競合）。

---

## 4. トラブルシュート（抜粋）

| 症状 | 確認 |
|------|------|
| Agent 不可 | LLM ON・モデル追加・ポート 8080・Ollama 停止・`llama-server.exe` 配置 |
| SmartScreen | 社内アルファ想定で「実行」 |
| Swift 補完が出ない | Windows では非対応（仕様） |
