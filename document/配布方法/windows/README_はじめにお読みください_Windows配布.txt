【位置づけ】

  本アプリ（LMCode）はコーディングアシスト専用です。
  Windows でも **S16（コーディング UI）** が起動画面です。
  Swift 補完は macOS のみ（Windows では利用できません）。

【このフォルダの中身】

  インストール手順_アルファ_Windows.md
      → 詳細手順

  （配布 zip がある場合）
  LMCode-Windows.zip 等
      → アプリ本体の一式

  local_llm\
      → ローカル AI 用（llama-server.exe）。GGUF はユーザー追加が原則

--------------------------------------------------------------------------------
【最短セットアップ】

  1. zip を展開し、好きな場所へ置く
  2. lmcode.exe を起動（S16 コーディング画面）
  3. エンジン設定から「モデルを追加」で GGUF を取り込む
  4. コーディング用モデルを選んで保存

  ※ data フォルダや *.dll は exe と同じ場所に置いたままにしてください。
  ※ SmartScreen が出たら「詳細情報」→「実行」（社内アルファ想定）。

--------------------------------------------------------------------------------
【注意】

  * 会議・文字起こし・仮想マイクは本アプリの対象外です。
  * GGUF のライセンス・利用条件は利用者自身の責任です。
  * Ollama を併用している場合は停止してください（ポート競合）。
