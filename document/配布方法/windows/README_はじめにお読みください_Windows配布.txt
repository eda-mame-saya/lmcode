【位置づけ】

  本アプリ（LMCode）はコーディングアシスト専用です。
  現時点の製品方針では **S16（コーディング UI）は macOS のみ**。
  Windows は入口非提供（GPU 搭載機のみ将来検討）。
  本フォルダの手順は、将来の Windows 配布・社内検証用の下書きです。

【このフォルダの中身】

  インストール手順_アルファ_Windows.md
      → 詳細手順（下書き）

  （配布 zip がある場合）
  LMCode-Windows.zip 等
      → アプリ本体の一式

  local_llm\
      → ローカル AI 用（llama-server）。GGUF はユーザー追加が原則

--------------------------------------------------------------------------------
【最短セットアップ（検証用・将来）】

  1. zip を展開し、好きな場所へ置く
  2. lmcode.exe を起動
  3. S16 が無効なビルドではエンジン設定（S11）へ遷移しうる
  4. 「モデルを追加」から GGUF を取り込む

  ※ data フォルダや *.dll は exe と同じ場所に置いたままにしてください。
  ※ SmartScreen が出たら「詳細情報」→「実行」（社内アルファ想定）。

--------------------------------------------------------------------------------
【注意】

  * 会議・文字起こし・仮想マイクは本アプリの対象外です。
  * GGUF のライセンス・利用条件は利用者自身の責任です。
  * Ollama を併用している場合は停止してください（ポート競合）。
